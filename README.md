# 🎓 Student Analytics & AI Risk Portal

An interactive web application built with **Flask**, **SQLite**, and **Scikit-learn** to evaluate student performance in real-time and predict academic risk using Logistic Regression.

## 🚀 Features
- **Real-Time Analytics**: Visual breakdown of class average, total students, and students at risk.
- **Machine Learning Integration**: Uses Logistic Regression (`scikit-learn`) to predict student risk levels based on attendance and marks.
- **Full CRUD Operations**: Add new student entries and undo/delete records dynamically.
- **Modern UI**: Dark glassmorphism interface built with responsive HTML5, CSS3, and JavaScript fetch API.

## 🛠️ Tech Stack
- **Backend**: Python, Flask, SQLite3
- **Machine Learning**: Scikit-learn, NumPy
- **Frontend**: HTML5, CSS3, JavaScript (Fetch API, FontAwesome)
